----> I don't store the astrometric data for cross-matches in the main output file, so I have had to generate a file for each source that can be found in the sed/ directory. 
----> I've then used the following to produce the attached output file:

cd output/sed/
grep Gaia * | grep Gmag | awk '{print $1,$3,$4}' | sed 's/.sed:Gaia//g' > ../../foo
cd ../anc/
grep -re 'RA\|Dec' . | awk '$0~":RA" {printf "%s ",$1} {printf "%s %s ",$4,$5} $0~"PMDec" {printf "\n"}' | sed 's/.\///g' | sed 's/.anc:RA//g' > ../../bar
cd ../../
awk '{sub(/^\.\//, ""); print}' foo > foo1
join -1 1 -2 1 <(sort -k1b,1 foo1) <(sort -k1b,1 bar) > gaia-offset.dat
